# Dataset provenance

The application uses `Loan.csv`, supplied by the user from Kaggle. It contains
20,000 rows and a `LoanApproved` target. The project also contains the exact
reproducible split used by the model: `train.csv` has 16,000 rows and `test.csv`
has 4,000 rows. The older `loan_approval_dataset.csv` and
`loan_applications_synthetic.csv` are retained as reference files but are not
used by the website.

Check the original Kaggle page for the dataset's license and attribution terms.
This project is for demonstration only and must not be used to make real
lending decisions.
